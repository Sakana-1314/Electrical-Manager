功能总览 ​

服务对象：华星镍业检修维护部电气自动化车间。不涉及物资价格和成本核算。

功能清单 ​

模块功能说明
库存模块库存管理二级库物资与库存余额、入出库流水；流水可修正、冲销并自动重算后续余额。
库存模块补库与低库存按近 6 个月出库计算建议数量，库存查询的低库存视图可一键发起补库。
库存模块二级库管理（小程序）持 warehouse:write 的用户可在小程序端维护物资档案（新增 / 编辑 / 删除，含图片）并扫码或选物资入库；接口是同名管理端能力的薄适配（/mini-program/stock-materials*、/mini-program/inbound），不是第二套 SQL。
库存模块二级库 Lite独立台账（lite_inventory）：后台 Excel 全量导入与只读查询、小程序端只读查看；与二级库 Pro 是两套独立权限，可单独或同时授予。小程序首页「二级库 Pro」与「二级库 Lite」两个入口同时持有时都展示、各自进对应数据源；出入库记录入口在二级库 Pro 库存页顶部操作条，扫码入库入口在二级库管理（物资档案）页，Pro 列表卡左上角显示首次入库时间。
申购模块申购计划可暂缺物料编码，到货时关联或新建二级库物资；支持周期性计划模板。
申购模块请购与到货按申购单号管理，状态取自外部平台并随平台数据升级或回退：已申购 ↔ 已采购 ↔ 部分入库 ↔ 已入库。
采购跟踪采购跟踪按申购单号整单同步外部平台（采购人、合同号、合同签订日期、船号、状态），只补空值。
数据协同Excel 导入导出布局模板随代码版本管理；导入导出走异步任务并提供进度查询。
数据协同链接分享生成带失效时间的匿名分享页，可配置公开页展示列。
隐患管理隐患管理隐患台账：检查信息与责任单位登记、整改前/后图片、整改状态与逾期跟进，按类型/状态/等级/单位/整改员工/区域/日期筛选；小程序端可登记隐患、更新整改状态并上传整改图片。
隐患管理隐患类型与责任单位隐患类型按「大类 + 小类」组合维护，页面以两级横向树展示（大类在左、小类在右，大类可折叠）；责任单位与责任人一一对应，可停用；两者被隐患引用时不可删除。
台账管理台账总览电气台账记录：子项号 / 名称 + 型号（合并一列两行展示）/ 标签 / 数量（与单位合并展示，如「12 台」）/ 用途 / 备注 / 图片，一条记录可挂多个标签；按关键字与标签（命中选中标签及其全部子孙标签）筛选与分页，整行点击编辑；小程序端只读查看（列表逐个展示 + 关键字搜索 + 点开详情）。
台账管理标签管理分层标签树（至多 3 层），每个节点可配名称 / 备注 / 图片 / 上级标签（可改上级、也可移为一级标签）；页面以横向树展示，各层节点样式一致，节点上的数字是「使用该标签的台账记录数」（只算直接挂这个标签的记录，不含子标签的使用量，含 0），节点悬停浮层看备注与图片、加号预选当前节点新增子标签，可按「孤立标签 / 树标签」筛选；有子标签或被台账引用的标签不允许删除。
工作管理工作任务一行一个任务，列与车间《任务详细计划》表一致：工作任务 / 事项或步骤 / 开始时间 / 完成时间 / 责任人 / 完成度 / 备注，另加标签与图片；按标签（可多选，命中任意一个）/ 完成状态（未完成 / 已完成）/ 关键字筛选与分页，整行点击编辑，图片可在行内预览。
平台能力图片附件上传与缩略图预览，按 file_id 读取，含悬空文件清理接口。
平台能力水印相机小程序端现场拍照工具：照片自动叠加时间 / 日期星期 / 地点 / 文案四行水印后存入相册，支持先拍后写与先写后拍；水印项目在设置页逐项开关（拍摄页不重复一套开关），常用词可置顶与增删，设置只存本机。
系统管理项目管理维护项目列表本身（名称、启停、唯一默认项目）；有业务数据的项目不允许删除。
系统管理附件管理列出全部图片与被引用次数（含待删除附件，其预览缩略图照常展示、降透明度区分，便于判断是否撤销）；可删除单张或一键删除全部未引用图片，均为软删除，保留 7 个完整自然日后的第一个凌晨 2 点定时复查引用后才物理清除文件与记录（保留期内可随时撤销删除）；「删除未引用」会先给出预检清单（会被标记的数量与明细、因上传未满 7 天的保护期而跳过的数量），确认后才执行。
系统管理附件管理列出全部图片与被引用次数（含待删除附件，其预览缩略图照常展示、降透明度区分，便于判断是否撤销）；可删除单张或一键删除全部未引用图片，均为软删除，保留 7 个完整自然日后的第一个凌晨 2 点定时复查引用后才物理清除文件与记录（保留期内可随时撤销删除）；「删除未引用」会先给出预检清单（会被标记的数量与明细、因上传未满 7 天的保护期而跳过的数量），确认后才执行。
平台能力MCPMCP 工具：业务工具（库存查询与出入库、申购计划与记录、隐患、台账、工作任务、备忘录等）把网页端的默认筛选一并带过去（如申购计划默认只看「正常 + 未转入」、工作任务按开始时间倒序且标签命中任意一个），高级工具可调用全部管理端接口（只排除登录/刷新与小程序专用接口）；按接口令牌对应用户的权限位鉴权，链接可带 project_id 指定操作的项目，附件与带乐观锁的写操作都能通过工具完成。
平台能力备忘录多条纯文本备忘录（左侧列表 + 单编辑区），字号可调并记录在浏览器本地。
用户与权限登录方式网页端优先使用微信小程序扫码登录（默认页签），同时保留账号密码登录：扫码会话使用 UUID、只存在服务端内存（5 分钟过期），小程序确认后网页一次性换取登录令牌；小程序首页「扫一扫」是物资码与网页登录码的统一入口（所有已登录用户都可用），扫到登录码直接进确认页。
用户与权限管理后台用户按 14 个权限位（系统管理 + 各功能读写；二级库 Pro 与二级库 Lite 是两套独立权限，物料编码库并入申购）逐项分配权限，写权限自动包含同模块查看；网页端与小程序端共用同一套账号与权限，不再区分来源；高级设置可配置新用户默认权限；微信身份支持人工合并，接口令牌加密入库并回显。
用户与权限进入网页版（小程序）小程序「个人信息」页的「进入网页版」：小程序登录响应同时下发小程序令牌与网页端管理 JWT（web_access_token，与网页密码登录同款、同一用户与权限位），点击时把后者直接带在 /web-open?token=… 上，再用 wx.openEmbeddedMiniProgram 半屏唤起御坂学习中转小程序的 web 页（中转小程序不可用时回落到本站 pages/web-view）；网页令牌从地址栏读取后立即清除，再用 /auth/me 补齐用户与权限并落到工作台。小程序令牌仍只能访问 /mini-program/*。后端未配置 APP_WEB_BASE_URL 或旧版登录响应没有该字段时，回退到一次性票据（2 分钟、只能兑换一次，只存在服务端内存）。
用户与权限用户设置左下角用户菜单进入：个人资料只读，可复制自己的 MCP 地址 / 令牌；只能修改密码（从未设置密码的扫码账号可设置第一个密码）。

业务边界 ​

边界说明
只管理数量不涉及物资价格、金额、税率与成本核算；init.sql 中没有任何金额字段。
合同 / 船期只做记录合同号、船号、集港 / 发船日期、业务员是申购记录上的自由文本与日期字段；没有合同、供应商、付款单据管理。
没有通用审批流引擎请购与申购状态是可编辑字段加「以平台数据为准」的双向同步规则，见状态机。
不建人员名册与工时工作管理的责任人只是任务上的文本（可多人在一个字段里），没有人员档案、班组、工时与成本统计；标签也只是任务上的英文逗号分隔字符串，没有标签维护页。
没有库位与批次无库位、批次、序列号、保质期、盘点差异单；库存调整只能靠入库、出库、修改流水或冲销流水。
允许负库存出库不校验余额是否充足，库存余额可以为负。

权限位能力 ​

权限是用户记录上的 BIGINT 位图（app_user.permissions），管理端与小程序端共用；「用户管理」里直接勾选，没有角色表。写权限保存时自动带上同模块读权限。

权限键位能力
system:admin1用户与项目管理、高级设置、附件池、分享链接治理
warehouse:read2二级库 Pro 库存、操作记录、小程序库存查看
warehouse:write4二级库 Pro 物资、库存策略、入库 / 出库 / 冲销、小程序出库
lite:read8192二级库 Lite 查看（Excel 导入的只读台账）
lite:write16384二级库 Lite Excel 全量导入
purchase:read8申购计划 / 记录 / 物料编码库查看
purchase:write16申购计划与记录编辑、转入 / 恢复、采购跟踪回写、编码库导入
huaxing:read32华星总库存查看
huaxing:write32768华星总库存 Excel 全量导入
ledger:read128台账与标签查看
ledger:write256台账记录、标签与标签图片维护
hazard:read512隐患台账查看
hazard:write1024隐患登记 / 整改、隐患类型与责任单位维护
work:read2048工作管理查看
work:write4096工作任务与任务图片维护

系统管理位与全部功能读写位同时打开（65471；位 6 原 codes:read 已退役保留空位）等价于旧的「超级管理员」，但它只是权限位的并集，不再是独立角色。逐接口的权限依赖见架构设计。
