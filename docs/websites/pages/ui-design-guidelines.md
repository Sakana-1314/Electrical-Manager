# UI 设计规范

## 原则

| 原则 | 要求 |
| --- | --- |
| 信息优先 | 视觉层级服务于业务信息，不做无意义装饰与重复说明 |
| 页头克制 | 列表页页头只放标题与必要操作，不在标题下重复解释页面名称 |
| 一致分组 | 筛选、数据、详情、编辑统一使用卡片容器 |
| 单一主色 | 交互主色用蓝色；绿色只表达成功语义 |
| 复用优先 | 相同交互必须复用公共组件或全局样式，不复制页面级实现 |

`--color-surface-muted`，不用蓝色系底色。

## 界面外观（明 / 暗）

| 项 | 要求 |
| --- | --- |
| 档位 | 三档：`auto`（自动，跟随系统，默认）、`light`（浅色）、`dark`（深色）；档位存浏览器本地 `theme.mode`，不落库、不产生请求 |
| 入口 | 顶栏用户下拉里的「外观」二级菜单：鼠标悬浮父项「外观」，向左浮现自动 / 浅色 / 深色三档（顶栏在最右上角，子菜单空间不足时自动向左展开），当前档勾选 |
| 解析 | `auto` 时用 `prefers-color-scheme` 实时判断；用户显式选择后固定该档，覆盖系统设置，刷新与换页都保持 |
| 落地 | 解析结果写到 `<html data-theme="light|dark">` 与 `color-scheme`；`styles.css` 的颜色令牌按该属性整套切换；Naive UI 组件由 `n-config-provider` 同时切到 `darkTheme` + 深色调色板覆盖 |
| 首屏 | `index.html` 在入口脚本前用同一规则预置 `data-theme`，避免刷新时先浅后深的闪烁；app 启动后再由 store 校正 |
| 不设快捷按钮 | 顶栏不放独立的明暗切换图标，外观只从「外观」二级菜单切换（避免同一功能两个入口） |
| 新增样式 | 只引用上文令牌，不写死颜色；确需新颜色时先在设计令牌表里加一组浅 / 深值，再引用变量 |

小程序端沿用同一套三档语义与令牌分层；深色档的**页面底比网页端更暗、容器更亮**（手机在环境光下容易糊成一片），
因此深色档按「页面底 < 卡片/弹窗 < 搜索框与输入框」三级递增明度，不直接照搬网页端色值：

| 项 | 要求 |
| --- | --- |
| 档位与存储 | 同样三档 `auto`（跟随系统，默认）/ `light` / `dark`，档位存本机 storage `miniProgramThemeMode`，不落库、不产生请求 |
| 入口 | 首页「个人信息」弹窗里的「外观」下拉菜单（收起态显示当前档位，展开后用 `t-radio-group` 列出三档），不另加切换入口 |
| 落地 | 浅色令牌定义在 `app.wxss` 的 `page`，深色同名覆盖在 `.theme-dark`（由 `themeClass` 加到各页面根节点）；`page, .theme-dark` 把 TDesign 的 `--td-*` 桥接到 `--app-*` |
| 深色层次 | 深色邻接色阶至少留出可辨差异（页面底 → 卡片/弹窗 → 控件），不靠描边单独撑层次；`--app-bg` / `--app-surface` / `--app-surface-soft` 三级递增 |
| 原生外观 | `app.json` 的 `darkmode` + `themeLocation` 让窗口与导航栏跟随系统；显式档由 `wx.setNavigationBarColor` / `wx.setBackgroundColor` 纠正 |
| 新增样式 | 页面与组件样式只引用 `--app-*` 令牌，不写颜色字面量，也不用 `@media (prefers-color-scheme)` 切换主题；新增令牌时明暗两档必须同名同义（`npm run check` 在 `miniprogram/` 下校验） |

## 小程序页面约定

小程序与网页端共用同一套令牌、三档语义与文案（`utils/i18n.js` 的 `zh-CN` / `id-ID` 键集合必须一致），
交互控件按移动端实现：列表页统一「搜索 + 筛选下拉 + 结果计数 + 状态面板」，登记与详情页统一「卡片分组 + 底部主按钮」。

| 项 | 要求 |
| --- | --- |
| 列表页骨架 | 根节点 `class="page-shell … {{themeClass}}"`；自上而下依次为页标题、`t-search`、（有筛选时）`t-dropdown-menu`、结果计数、列表卡片、状态面板 |
| 搜索 | `t-search`（`shape="round"`、`confirm-type="search"`），只搜该页约定字段：隐患管理只匹配检查区域与隐患描述 |
| 筛选下拉 | `t-dropdown-menu` + `t-dropdown-item`，选项通过 `options` 传入、当前值走 `value`；**首项固定为「全部××」（`value: ''`）**。网页端「下拉不放『全部』选项、清空即不限」的规则不适用于小程序：这里没有清空态，必须显式给出不限项 |
| 主操作 | 列表页的登记/新增入口用 `t-fab` 悬浮圆钮，只在有写权限时渲染（见 `utils/features.js`） |
| 状态面板 | 加载中用 `t-loading`，无数据用 `t-empty`；「本来为空」与「筛选后为空」用不同文案，避免误导 |
| 反馈 | 轻提示用 `Toast({ context: this, selector: '#页面-toast' })`，需要提示的页面在 WXML 里放一个对应 id 的 `t-toast`（纯静态提示页如「停用」「注册已关闭」除外） |
| 只读档位 | `query_only` / `disabled` 档位下不渲染写入口（FAB、上传、提交按钮），页面仍能完整展示数据 |


## 页面结构

### 页头

```html
<div class="page-header">
  <div>
    <h1 class="page-title">页面标题</h1>
  </div>
  <div class="page-actions">
    <n-space>页面操作</n-space>
  </div>
</div>
```

| 场景 | 要求 |
| --- | --- |
| 列表页 | 不使用 `page-subtitle` |
| 详情页 | 标题下可显示一行关键元数据（编号、状态、时间、型号），最多一行 |
| 业务规则 | 放进对应卡片、表单提示或 `n-alert`，不写在页头 |
| 操作区容器 | 页头右侧控件统一放进 `.page-actions`（不直接与标题同级），便于窄屏统一压缩；隐藏的 `file input` 随按钮放在容器内即可 |
| 移动端标题 | 顶栏已展示当前页面标题，**移动端隐藏内容区标题**（`.page-title`），只留操作区；桌面端内容区标题保持展示 |
| 移动端操作区 | 页头多个按钮必须排在同一行：`styles.css` 里统一把 `.page-actions` 内按钮字号压到 13px、内边距收窄，按钮组按内容宽度不压缩，超出时由操作区横向滑动承接，不换行、不把页面撑宽 |

### 顶栏标题（面包屑）

| 项 | 要求 |
| --- | --- |
| 层级 | 标题层级由路由 `meta.title` + `meta.parent` 提供：桌面端展示「上级 / 当前」，移动端只展示当前标题（宽度不够）；顶级条目（工作台、备忘录、二级库、华星总库存）不设 `meta.parent`，只展示当前标题，不在顶栏挂「备件管理」这类根名称 |
| 上级取值 | 二级条目用所属菜单分组名（二级库 / 申购管理 / 隐患管理 / 台账管理 / 系统管理），详情页与操作页用所属列表页标题或所属入口标题，让“能返回哪里”一眼可读 |
| 浏览器标题 | 与面包屑同源：`meta.parent / meta.title - HXNI 电气无忧`，不另外拼一套文案 |
| 详情页 | 详情页标题用短名（如「物资详情」），避免与上级标题重复成「物资档案 / 物资档案」 |

### 侧栏导航

| 项 | 要求 |
| --- | --- |
| 宽度 | 展开 `180px`、折叠 `64px`（`AppLayout.vue` 的 `n-layout-sider`）；移动端用抽屉，宽 `250px` |
| 菜单字号 | `13px`（`theme.ts` 的 `Menu.fontSize` 覆盖，明暗同值），比正文小 1px；展开态图标由菜单 `iconSize`（20px）决定，不随字号变化 |
| 品牌行 | 侧栏顶部品牌行：字号 `15px`、Logo `30px`、左右内边距 `13px`，`180px` 下「HXNI 电气无忧」仍完整显示（约余 9px）。**品牌名完整显示是侧栏宽度下限的判据**——再窄要么继续收品牌行，要么只能省略号兜底 |

### 卡片与筛选区

| 项 | 要求 |
| --- | --- |
| 卡片 | 页面内容统一 `n-card`；筛选卡片加 `filter-card`（轻微蓝灰渐变），数据表卡片加 `data-card`；不在单页重设圆角/阴影/边框 |
| 简单筛选 | `filter-bar`，控件间距 `10px` |
| 多条件筛选 | 用栅格形式（`filter-grid`，列最小宽度由全局变量 `--filter-col-min-width` 统一控制，190px），保留一个“筛选条件”标题 |
| 筛选卡片说明 | 标题下**不放小字描述**：筛选口径、选项含义、数据条数都不在筛选卡片里解释（重复说明只会挤占首屏）；需要提示“未选择”的含义时写进控件 `placeholder`，口径本身写进文档 |
| 筛选折叠 | 收起时按 DOM 顺序保留前 N 个筛选项：**桌面端 6 个**（约一排）、**手机端 2 个**（≤768px，列宽只够一个）；其余由筛选卡片标题右侧的 `FilterExpandButton`（文案“更多筛选 / 收起筛选”）展开。页面只给 `.filter-grid` 绑 `is-collapsed`（即 `!filterExpanded`），可见数量与“没有可展开项时不显示按钮”都由 `styles.css` 按断点统一决定——页面不写折叠逻辑、不加断点规则。**约束**：`.filter-grid` 的直接子元素只能是筛选项（`label.filter-field`），折叠按子元素序号计数；日期区间等宽控件用 `filter-field-wide`（跨两列） |
| 文本搜索 | 多关键词用半角 `|` 表示“或”（兼容全角 `｜`）；同一输入框内按 OR，不同控件之间按 AND；不在占位文字里重复该规则 |
| 下拉筛选 | 只列具体的筛选项，**不放“全部”选项**——清空选择即代表不限；控件加 `clearable` 并写 `placeholder` 说明该条件，让“未选择”可读、可撤销 |
| 按钮 | 主按钮为“查询”，重置为次按钮并与查询相邻；查询/重置不受筛选折叠影响，始终可见 |

### 数据表格

| 项 | 要求 |
| --- | --- |
| 表头 | 浅灰蓝背景 + 中等字重 |
| 行悬停 | 淡蓝背景，不改文字颜色 |
| 分页 | 卡片底部右侧，带顶部分隔线 |
| 操作列 | 行点击进详情时，仍保留明确文字操作或可感知的鼠标状态 |
| 列宽 | 统一引用 `web/src/constants/table.ts`，见下表 |
| 字段选择 | 列多且用户只关心其中几列时，筛选操作行放 `ColumnVisibilityPicker`（文案“已显示 N 个字段”）：列定义抽成 `availableColumns`（`key` + `label` + `column`），可见列用 `ref` 驱动 `computed` 过滤，`scroll-x` 用过滤后的列重算；默认全选、至少保留 1 列，勾选结果按 `storage-key="<模块>.<页面>.visible-columns.v<N>"` 存 localStorage，字段变动时递增 `v` 版本 |
| 压缩控制 | 每列同时设 `width` 与相同 `minWidth`；`scroll-x` 按实际列宽计算，超宽时横向滚动，不靠等比压缩牺牲名称/型号列 |
| 普通表格 | `n-table` 必须放进 `table-scroll` 容器，并设符合字段数量的最小宽度 |

| 内容类型 | 列宽 |
| --- | --- |
| 单位、状态、数量等短字段 | `80–110px` |
| 日期、人员、编码等中等字段 | `112–176px` |
| 名称 | `220px` |
| 型号规格 | `240px` |
| 物资摘要（名称 + 型号） | `280px` |
| 用途、原因等长文本 | ≥ `200px`，并提供省略提示 |

### 横向树（`vue3-tree-org`，至多三级）

有父子层级、且层级要在页面上看得见的数据用该组件呈现为横向树：**父节点在左、子节点在同一水平带上向右展开**，父子连线由组件自带的 CSS 伪元素绘制，页面**不自绘 SVG 或边框**。目前两处使用：隐患类型（一行一个「大类 + 小类」组合）与台账标签（真父子层级，至多 3 层）。

| 项 | 要求 |
| --- | --- |
| 触发条件 | 数据确实是父子结构（两级起、至多三级）且层级要在页面上可见时使用；纵向缩进场景用 `n-tree`，不要用它 |
| 数据 | 传**新建对象**（如 `buildHazardTypeTree()` / `buildLedgerTagTree()` 的产物），不要把接口列表直接传入——组件会往节点写 `$` 前缀字段 |
| 共享类名 | 容器统一挂 `.org-tree-horizontal`（`web/src/styles.css` 的「横向树（vue3-tree-org）」段）：隐患类型页与台账标签页共用同一段样式，页面只再挂自己的层级 class（如 `.hazard-type-tree`、`.ledger-tag-tree`），不另写一套 |
| 必需属性 | `horizontal`、`collapsable`；同时关闭 `draggable` / `scalable` / `node-draggable` / `tool-bar`，并传 `:define-menus="[]"` 关掉右键菜单，避免出现「新增/删除节点」等与业务无关的入口 |
| 根节点 | 组件要求单个根对象。多个顶层分组时用一层无标签虚拟根承载，并在样式里隐藏该根（空标签节点带 `is-empty`） |
| 操作范围 | 看数据模型：隐患类型只有**叶子**是业务实体行，分组不提供整组改名/删除；台账标签每个节点都是实体（都可改名称 / 备注 / 图片 / 上级标签），删除受「有子标签或被台账记录引用」保护 |
| 节点悬停浮层 | 节点上还有备注、图片这类一屏放不下的信息时，用 `n-popover`（`trigger="hover"`）承载：浮层只读，展示备注与图片缩略图；两者都没有的节点不弹浮层 |
| 层级上限 | 层级有上限时（台账标签至多 3 层），到第 3 层的节点不再提供「新增子标签」入口；前端隐藏只是体验，上限由服务端一并校验 |
| 层级不分主次 | 同一棵树里的节点样式一致（同字号、同字重、同内边距）：层级由连线与缩进表达，**不用字号 / 字重 / 卡片大小区分层级**；要补充的信息用数字计数（如台账标签的「3」表示 3 条台账使用该标签，含义放 tooltip）或中性小字，不用彩色标签堆在节点里 |
| 节点操作入口 | 节点上的操作（如台账标签的「新增子标签」）用图标按钮 + tooltip 说明，不用整词按钮；入口只在未达上限且有写权限时渲染，默认透明、悬停节点才显现，因此点击处理要忽略落在该按钮上的点击（`closest('.ledger-tag-node__add')`），否则点按钮会连带触发节点自身的编辑 |
| 样式 | 组件自带布局面向「可拖拽组织图」（外框白底、内容层绝对定位、内层 `height:100%`），放进卡片会高度塌陷且深色档露白底。`web/src/styles.css` 的「横向树（vue3-tree-org）」段已统一还原为文档流并映射 `--color-*` 令牌；新页面复用同一段（挂 `.org-tree-horizontal`），不要另写一套 |
| 溢出 | 容器设 `overflow: auto`；树比卡片宽时容器内横向滚动，页面整体不出现横向滚动条 |

## 图片附件

统一使用 `web/src/components/ImageUploader.vue`，不得在页面内新增原生文件选择器或另一套上传卡片。

| 项 | 要求 |
| --- | --- |
| 表单标签 | 统一写“图片附件” |
| 格式与数量 | JPG、PNG、WebP；单张 ≤ 10 MB；默认最多 9 张 |
| 交互 | 点击选择与 `Ctrl+V` 粘贴 |
| 组件职责 | 缩略图、删除按钮、禁用态、上传中状态由组件处理 |
| 页面职责 | 只用 `v-model:files` 绑定文件列表，不自行拼预览地址或删除逻辑 |

```html
<n-form-item label="图片附件">
  <ImageUploader v-model:files="images" />
</n-form-item>
```

## 状态与反馈

| 语义 | 颜色 |
| --- | --- |
| 主操作 | 主题蓝色 |
| 成功 / 启用 / 已完成 | 绿色 |

### 加载遮罩

| 场景 | 组件与要求 |
| --- | --- |
| 局部加载 | `web/src/components/LoadingMask.vue`：模糊遮挡 + 居中 loading（可带一行文案），不用整页遮罩 |
| 宿主元素 | 遮罩范围由宿主决定（`position: absolute`），宿主需有定位上下文；`.page`、`.n-card`、`.share-table-card`、`.settings-grid` 已提供 |
| 禁用 | 禁止页面内自造遮罩样式或恢复“整块变淡”的旧做法 |
| 整页阻塞 | 仅限导出等全局操作（`ExportLoadingOverlay`） |
| 防重复提交 | 确认弹窗统一用 `web/src/composables/useImportConfirm.ts`：确认后按钮立即转圈并禁用，同时禁用取消/遮罩/Esc 关闭 |

## 实现约束

| 项 | 位置 / 要求 |
| --- | --- |
| Naive UI 主题覆盖 | `web/src/theme.ts` |
| 跨页面布局与视觉类 | `web/src/styles.css` |
| 表格列宽令牌 | `web/src/constants/table.ts` |
| 单页样式 | `<style scoped>` 只保留该页独有的布局或交互样式 |
| 颜色 | 优先用 CSS 变量或主题令牌，避免新增硬编码色值 |
| 组件复用 | 新增重复 UI 前先查 `web/src/components` 是否已有可复用组件 |
| 图标 | `NIcon` + `@vicons/ionicons5`（如 `web/src/layouts/AppLayout.vue` 侧栏），不手写内联 SVG 或字符占位（唯一例外：筛选折叠箭头，`web/src/components/FilterExpandButton.vue` 的内联 SVG，Naive UI 无对应图标）；尺寸与居中交给组件库（`collapsed-icon-size` / `icon-size`），不用 margin/padding 手工微调 |
| 菜单图标 | **只给一级菜单项配图标**：侧栏折叠时只渲染一级图标，二级项图标永远不会出现，加了只是多余噪音；二级项靠缩进区分层级 |
