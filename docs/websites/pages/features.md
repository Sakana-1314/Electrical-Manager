# 功能总览

服务对象：华星镍业检修维护部电气自动化车间。**不涉及物资价格和成本核算。**

## 功能清单

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 库存模块 | 库存管理 | 二级库物资与库存余额、入出库流水；流水可修正、冲销并自动重算后续余额。 |
| 库存模块 | 补库与低库存 | 按近 6 个月出库计算建议数量，库存查询的低库存视图可一键发起补库。 |
| 库存模块 | 精简库存 | 精简/完整模式开关；精简库存独立表、小程序只读、后台单页导入查询。 |
| 申购模块 | 申购计划 | 可暂缺物料编码，到货时关联或新建二级库物资；支持周期性计划模板。 |
| 申购模块 | 请购与到货 | 按申购单号管理，状态取自外部平台并只进不退：已申购 → 已采购 → 部分入库 → 已入库。 |
| 采购跟踪 | 采购跟踪 | 按申购单号整单同步外部平台（采购人、合同号、合同签订日期、船号、状态），只补空值。 |
| 数据协同 | Excel 导入导出 | 布局模板随代码版本管理；导入导出走异步任务并提供进度查询。 |
| 数据协同 | 链接分享 | 生成带失效时间的匿名分享页，可配置公开页展示列。 |
| 隐患管理 | 隐患管理 | 隐患台账：检查信息与责任单位登记、整改前/后图片、整改状态与逾期跟进，按类型/状态/等级/单位/整改员工/区域/日期筛选；小程序端可登记隐患、更新整改状态并上传整改图片。 |
| 隐患管理 | 隐患类型与责任单位 | 隐患类型按「大类 + 小类」组合维护，页面以两级横向树展示（大类在左、小类在右，大类可折叠）；责任单位与责任人一一对应，可停用；两者被隐患引用时不可删除。 |
| 台账管理 | 台账总览 | 电气台账记录：子项号 / 名称 + 型号（合并一列两行展示）/ 标签 / 数量（与单位合并展示，如「12 台」）/ 用途 / 备注 / 图片，一条记录可挂多个标签；按关键字与标签（命中选中标签及其全部子孙标签）筛选与分页，整行点击编辑；小程序端只读查看（列表逐个展示 + 关键字搜索 + 点开详情）。 |
| 台账管理 | 标签管理 | 分层标签树（至多 3 层），每个节点可配名称 / 备注 / 图片 / 上级标签（可改上级、也可移为一级标签）；页面以横向树展示，各层节点样式一致，节点上的数字是「使用该标签的台账记录数」（只算直接挂这个标签的记录，不含子标签的使用量，含 0），节点悬停浮层看备注与图片、加号预选当前节点新增子标签，可按「孤立标签 / 树标签」筛选；有子标签或被台账引用的标签不允许删除。 |
| 工作管理 | 工作总览 | 每天每个活由哪几个人在干：一行 = 日期 + 任务 + 时段（全天 / 上午 / 下午），末列列出当天参与人员；按日期区间（必填、最长 92 天）/ 任务 / 参与人员 / 关键字筛选与分页，点行查看或编辑那条工作记录。 |
| 工作管理 | 任务视图 | 每个任务一行，用半日格时间线看它的全周期：色块 = 一段起止时间（精确到上午 / 下午）与参与人员；可维护任务（名称 / 状态 / 计划起止 / 工作内容 / 备注 / 图片）与时间段（多人可填在一个字段里），点任务名看该任务的时间段明细。 |
| 工作管理 | 人员视图 | 每个人一行，用半日格时间线看他每天在干什么活；人员清单由工作记录里填过的姓名派生（不建人员名册，输入时有历史姓名下拉辅助），可直接给某人排活、点色块改那条记录。 |
| 平台能力 | 图片附件 | 上传与缩略图预览，按 `file_id` 读取，支持 CDN/图床加速，含悬空文件清理接口。 |
| 系统管理 | 项目管理 | 维护项目列表本身（名称、启停、唯一默认项目）；有业务数据的项目不允许删除。 |
| 系统管理 | 附件管理 | 列出全部图片与被引用次数（含待删除附件，其预览缩略图照常展示、降透明度区分，便于判断是否撤销）；可删除单张或一键删除全部未引用图片，均为软删除，保留 7 个完整自然日后的第一个凌晨 2 点定时复查引用后才物理清除文件与记录（保留期内可随时撤销删除）。 |
| 系统管理 | 后台可见功能 | 高级设置里按主 tab 逐项选「显示 / 隐藏」来收放后台侧栏入口（工作台 / 备忘录 / 二级库 / 华星总库存 / 申购管理 / 隐患管理 / 台账管理 / 工作管理）；系统管理固定显示，分组内部入口不单独配置；只从侧栏移除入口，路由与后端接口不拦（被隐藏的页面仍可用链接直达）。 |
| 平台能力 | AI 搜索与 MCP | AI 搜索配置（API Key 加密入库）与 MCP 工具：把全部管理端业务接口暴露给 AI Agent（只排除登录/刷新与小程序专用接口），按接口令牌对应的角色鉴权，链接可带 `project_id` 指定操作的项目，附件与带乐观锁的写操作都能通过工具完成。 |
| 平台能力 | 备忘录 | 多条纯文本备忘录（左侧列表 + 单编辑区），字号可调并记录在浏览器本地。 |
| 用户与权限 | 管理后台用户 | 七种角色、微信身份按 AppID 记录并支持人工合并，接口令牌加密入库并回显。 |

## 业务边界

| 边界 | 说明 |
| --- | --- |
| 只管理数量 | 不涉及物资价格、金额、税率与成本核算；`init.sql` 中没有任何金额字段。 |
| 合同 / 船期只做记录 | 合同号、船号、集港 / 发船日期、业务员是申购记录上的自由文本与日期字段；没有合同、供应商、付款单据管理。 |
| 没有通用审批流引擎 | 请购与申购状态是可编辑字段加「只进不退」的同步规则，见[状态机](/dev-state-machines)。 |
| 不做人员名册与工时 | 工作管理的参与人是工作记录上的姓名文本（可多人在一个字段里），没有人员档案、班组、工时与成本统计；同一人靠姓名文本归集，输入时用历史姓名下拉减少错别字。 |
| 没有库位与批次 | 无库位、批次、序列号、保质期、盘点差异单；库存调整只能靠入库、出库、修改流水或冲销流水。 |
| 允许负库存 | 出库不校验余额是否充足，库存余额可以为负。 |

## 角色能力

| 角色 | 可写 | 只读 |
| --- | --- | --- |
| 系统管理员 `SUPER_ADMIN` | 全部模块 + 用户与系统设置 | 全部 |
| 仓库管理员 `WAREHOUSE_ADMIN` | 二级库物资、库存策略、入出库、流水 | 申购模块、采购跟踪 |
| 申购管理员 `PURCHASE_ADMIN` | 申购计划、申购记录、物料编码库 | 库存模块 |
| 隐患管理员 `HAZARD_ADMIN` | 隐患台账、隐患类型、责任单位 | 其余业务数据 |
| 台账管理员 `LEDGER_ADMIN` | 台账记录、标签与标签图片 | 其余业务数据 |
| 工作管理员 `WORK_ADMIN` | 任务、工作记录与任务图片 | 其余业务数据 |
| 只读 `READ_ONLY` | — | 全部业务数据（含台账总览与工作管理三个视图） |

逐接口的权限依赖见[架构设计](/dev-architecture)。
