# 功能总览

服务对象：华星镍业检修维护部电气自动化车间。**不涉及物资价格和成本核算。**

## 功能清单

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 库存模块 | 库存管理 | 二级库物资与库存余额、入出库流水；流水可修正、冲销并自动重算后续余额。 |
| 库存模块 | 补库与低库存 | 按近 6 个月出库计算建议数量，低库存工作台一键发起补库。 |
| 库存模块 | 精简库存 | 精简/完整模式开关；精简库存独立表、小程序只读、后台单页导入查询。 |
| 申购模块 | 申购计划 | 可暂缺物料编码，到货时关联或新建二级库物资；支持周期性计划模板。 |
| 申购模块 | 请购与到货 | 按申购单号管理，状态取自外部平台并只进不退：已申购 → 已采购 → 部分入库 → 已入库。 |
| 采购跟踪 | 采购跟踪 | 按申购单号整单同步外部平台（采购人、合同号、合同签订日期、船名、状态），只补空值。 |
| 数据协同 | Excel 导入导出 | 布局模板随代码版本管理；导入导出走异步任务并提供进度查询。 |
| 数据协同 | 链接分享 | 生成带失效时间的匿名分享页，可配置公开页展示列。 |
| 隐患管理 | 隐患管理 | 隐患台账：检查信息与责任单位登记、整改前/后图片、整改状态与逾期跟进，按类型/状态/等级/单位/整改员工/区域/日期筛选；小程序端可登记隐患、更新整改状态并上传整改图片。 |
| 隐患管理 | 隐患类型与责任单位 | 隐患类型按「大类 + 小类」组合维护，页面以两级横向树展示（大类在左、小类在右，大类可折叠）；责任单位与责任人一一对应，可停用；两者被隐患引用时不可删除。 |
| 台账管理 | 台账总览 | 电气台账记录：名称 / 型号 / 子项号 / 数量（与单位合并展示，如「12 台」）/ 用途 / 备注 / 图片，一条记录可挂多个标签；按关键字与标签（命中选中标签及其全部子孙标签）筛选与分页，整行点击编辑。 |
| 台账管理 | 标签管理 | 分层标签树（至多 3 层），每个节点可配名称 / 备注 / 图片；页面以横向树展示，节点悬停浮层看备注与图片，可按「孤立标签 / 树标签」筛选。 |
| 平台能力 | 图片附件 | 上传与缩略图预览，按 `file_id` 读取，支持 CDN/图床加速，含悬空文件清理接口。 |
| 系统管理 | 附件管理 | 列出全部图片与被引用次数；可删除单张或一键删除全部未引用图片，均为软删除，次日凌晨 2 点定时复查引用后才物理清除文件与记录。 |
| 平台能力 | AI 搜索与 MCP | AI 搜索配置（API Key 加密入库）与 MCP 工具，供 AI Agent 按角色权限调用接口。 |
| 平台能力 | 备忘录 | 多标签纯文本备忘录，字号可调并记录在浏览器本地。 |
| 用户与权限 | 管理后台用户 | 六种角色、微信身份按 AppID 记录并支持人工合并，接口令牌加密入库并回显。 |

## 业务边界

| 边界 | 说明 |
| --- | --- |
| 只管理数量 | 不涉及物资价格、金额、税率与成本核算；`init.sql` 中没有任何金额字段。 |
| 合同 / 船期只做记录 | 合同号、船号、集港 / 发船日期、业务员是申购记录上的自由文本与日期字段；没有合同、供应商、付款单据管理。 |
| 没有通用审批流引擎 | 请购与申购状态是可编辑字段加「只进不退」的同步规则，见[状态机](/dev-state-machines)。 |
| 没有库位与批次 | 无库位、批次、序列号、保质期、盘点差异单；库存调整只能靠入库、出库、修改流水或冲销流水。 |
| 允许负库存 | 出库不校验余额是否充足，库存余额可以为负。 |

## 角色能力

| 角色 | 可写 | 只读 |
| --- | --- | --- |
| 系统管理员 `SUPER_ADMIN` | 全部模块 + 用户与系统设置 | 全部 |
| 仓库管理员 `WAREHOUSE_ADMIN` | 二级库物资、库存策略、入出库、流水 | 申购模块、采购跟踪 |
| 申购管理员 `PURCHASE_ADMIN` | 申购计划、申购记录、物料编码库 | 库存模块 |
| 隐患管理员 `HAZARD_ADMIN` | 隐患台账、隐患类型、责任单位 | 其余业务数据 |
| 台账管理员 `LEDGER_ADMIN` | 台账记录、标签与标签图片 | 其余业务数据 |
| 只读 `READ_ONLY` | — | 全部业务数据（含台账总览） |

逐接口的权限依赖见[架构设计](/dev-architecture)。
