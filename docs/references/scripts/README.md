# 油猴脚本

本目录存放备件管理系统配套的 Tampermonkey / Violentmonkey 用户脚本。

> 脚本的 `@updateURL` / `@downloadURL` 指向 raw 地址：
> `https://raw.githubusercontent.com/Sakana-1314/Electrical-Manager/main/docs/references/scripts/huayou-new-sync.user.js`
> 每次改内容都会递增 `@version`，脚本管理器检查更新时会自动升级。

## 只保留一个脚本

历史上有两个脚本按申购单号阈值分工（新版「印尼数据平台」负责 `>=` 阈值、旧版「何佳」负责 `<` 阈值）。
现在**旧版何佳脚本已删除**，只保留 `huayou-new-sync.user.js` 一个脚本：

| 项 | 说明 |
| --- | --- |
| 运行站点 | 华友印尼数据平台 `http://43.154.152.157:8080/` |
| 负责范围 | 全部申购单（不再按单号阈值切分；原阈值参数仍保留，可用来只看某段单号） |
| 数据来源 | 华友印尼数据平台「物料申购跟踪」报表 |
| 写入方式 | 按申购单号整单批量回写本系统（`/purchase-record-sync/orders/{申购单号}/apply`） |

## 登录态：网页弹窗授权（4.0 起）

**不再需要手工粘贴接口令牌**，也不再保存账号密码到脚本里换取令牌：

1. 在悬浮窗点「设置」→「网页授权登录」，脚本先调 `/auth/userscript-sessions` 建一个
   **一次性授权会话**，再弹窗打开本系统登录页
   （`/login?userscript=1&origin=…&session=…`，弹窗里可以用扫码或账号密码登录）；
2. 登录成功后点「授权脚本使用我的登录态」，网页把「当前用户」登记到该会话
   （`/auth/userscript-sessions/{id}/confirm`，只上报会话 id、不上传令牌）；
3. 脚本每 2 秒轮询同一会话，`confirmed` 时服务端签发 JWT 并**立即删除会话**（只能取一次），
   脚本把它存进脚本管理器私有存储（`GM_setValue`），后续接口用 `Authorization: Bearer <JWT>` 调用。

**为什么不靠窗口回传**：早期实现只靠 `window.opener.postMessage`，一旦发起窗口在点「授权」前
被刷新、关闭或被浏览器回收，opener 关系就断了，界面会报「发起窗口已关闭，授权未送达」。
现在会话通道是主路径，`postMessage` 只作为快速通道（opener 还在时省掉一次轮询）。
脚本建会话失败（旧版后端）时才退回纯窗口回传。

授权不经过任何第三方服务：会话只存在本系统后端进程内存、5 分钟过期、取一次即删除，
不落数据库；JWT 只落在脚本的私有存储里。相关代码见 `web/src/utils/userscriptHandoff.ts`
（网页侧）、`server/internal/service/userscriptauth`（会话存储）与脚本里的 `openWebAuth`。

### 多项目（数据隔离）

业务数据按项目隔离：悬浮窗设置里的「项目」下拉框列出**已启用项目**，默认选中系统默认项目
（原选择被停用时自动回退并记住）；业务接口统一带 `X-Project-Id`。**本地同步状态按项目隔离**：
翻页游标（`GM` 存储）与 3 天冷却记录（IndexedDB）都带项目 id。换项目后想立刻重跑：直接在下拉框
切换即可，冷却与游标都是各项目独立的一份。

## 华友印尼数据平台同步

脚本文件：`huayou-new-sync.user.js`

功能：

- 自动登录华友印尼数据平台，按「申购单号」整单查询“物料申购跟踪”，同一申购单号只发起一次
  平台查询，并在后端 `/purchase-record-sync/order-targets` 的目标基础上整单批量回写
  （`/purchase-record-sync/orders/{申购单号}/apply`），避免按追溯号逐条查询产生大量平台请求。
- 申购单号 `>= min_purchase_order_no`（默认 `P05SG0300`）只作为可选范围过滤；留空即处理全部申购单。
- 平台页面含 iframe 时（报表等内嵌页）只在**最外层窗口**注入悬浮窗，不会重复显示多份。
- 设置放在独立弹窗里（悬浮窗“设置”按钮打开）：网页端地址、登录态（网页授权登录）、项目与平台账号；
  弹窗内输入即自动保存，也可点“保存设置”确认。
- 设置弹窗里的“清除冷却”按钮只清除**当前项目**的 3 天冷却记录，并把该项目批次游标重置为 0；
  下次同步会重新查询平台（平台限频仍按 10 秒/单执行）。
- 平台相邻两次报表查询至少间隔 10 秒（限频）；登录不计入。
- 每个申购单最近一次成功同步的时间写入浏览器 IndexedDB（华友印尼数据平台站点域），
  3 天内不再重复请求同一申购单，避免频繁重复查询；演练模式不写记录。
- 采购人、采购合同号、船名只补空值；状态以平台报表推导结果为准、可进可退（已申购 ↔ 已采购 ↔
  部分入库 ↔ 已入库），与旧脚本语义一致；某申购单号下多个追溯号一次查询、一次回写。状态判定以平台报表的
  **入库时间** 列为准：只有入库时间有有效日期（非空、非 `1900-01-01` 之类占位值）时，才按
  入库数量判定「部分入库 / 已入库」；入库时间为空时即使平台已填入库数量，也只按采购数量 /
  采购合同号记「已采购」，避免仍在发运途中的物资被判成已入库。
- 因为状态可以回退，已入库的申购单也会进入同步目标（否则平台撤销入库时间后无法降级）；仍由
  3 天冷却和批次游标控制查询频率。已取消 / 已领用等本地状态不在后端同步白名单，不会被覆盖。
- 合同签订日期取自平台报表「物料申购跟踪」的 **合同签订时间** 列（据真实 HAR 的 `page/data`
  确认：该列为表头第 32 列，紧跟「采购合同号」之后），同样只补空值、不覆盖人工填写；该字段在
  本系统是**物资级**字段，按追溯号逐行回写。多个批次时取最新有效日期；平台若返回无法识别的
  日期文本则跳过该字段（宁可不填，也不写错日期）。
- 单价取自同一报表的 **采购单价** 列（据真实 HAR 的 `page/data` 确认：表头文本是
  `采购单价\nCNY`，其中 `\n` 为字面反斜杠 + n 两个字符，即列名带币种后缀，脚本按「采购单价」
  前缀匹配、也兼容改成「单价」的模板）；同样只补空值、不覆盖人工填写，与合同签订日期一样按
  追溯号逐行回写到申购记录的「单价」列。平台值会去掉千分位与 `¥`/`CNY` 前后缀后取两位小数；
  空值、0、负数或无法识别为价格的文本一律跳过（宁可不填，也不写错价格）。
- 集港日期 / 集港港口取自同一报表的 **国内集港日期** / **国内港口** 列（真实 HAR 表头即此名），
  回写到申购单头的 `consolidation_date` / `consolidation_port`（单据级，只补空值）：日期取最新
  有效值，港口去重后按「/」合并。平台把「无日期」写成 `1900-01-01` 之类占位值时跳过；
  报表没有这两列时同样只提示一次并继续同步其余字段。
- 兼容与提示：报表没有对应列时脚本会合并成一条日志提示并只同步其余字段；后端尚未更新
  （不认识新增同步字段）时按字段逐个降级为旧字段列表继续同步（先去掉单价、再去掉合同签订
  日期），不会整批中断。
- 首次请求对物料系统接口与本系统接口做严格结构校验；报表结构或接口契约与脚本不符时立即
  终止并给出日志，避免对一批申购单空跑、误写。
- 支持单次同步、自动模式（仅北京时间 02:00–06:00 执行）、单次申购单数和演练模式。
- 同步目标项目在「设置」弹窗里选择，默认使用系统的默认项目（已保存项目被停用时会自动回退并记住）；
  业务接口统一携带 `X-Project-Id`，项目未选择或已失效时脚本只提示一次并中止本次同步。
- 设置弹窗内容输入即自动保存到油猴本地存储；JWT 与平台密码都以明文显示（`type=text`），
  请仅在个人电脑上使用。

安装与使用：

1. 在 Tampermonkey 或 Violentmonkey 中新建脚本，粘贴 `huayou-new-sync.user.js` 的完整内容并保存。
2. 打开华友印尼数据平台站点 `http://43.154.152.157:8080/`（悬浮窗在该网站右下角出现）。
3. 点悬浮窗“设置”按钮打开设置弹窗，先点「网页授权登录」在弹窗里登录本系统并授权，再确认
   网页端地址（默认与脚本一致）与项目；物资平台账号默认是 `huaxing_jianxiu`。授权后“项目”下拉框
   会列出已启用的项目（默认选中系统默认项目），同步只写入所选项目的数据。
4. 关闭“演练模式”后正式写入（默认已关闭演练模式）。需要忽略 3 天冷却强制重查时，点设置弹窗里的
   “清除冷却”（只清当前项目，并重置批次游标）。

凭据（JWT 与平台账号密码）保存在用户脚本管理器的私有存储中，不写入仓库源码或网页 `localStorage`。查询时脚本会在
后台短暂打开参数化报表页，得到结果后自动关闭。脚本 3.x 依赖后端“按申购单号整单目标/回写”
接口（见 `server/app/api/v1/purchase_record_sync.py`）；合同签订日期与单价分别需要后端满足
`purchase-record-sync` 字段白名单包含 `contract_sign_date`、`unit_price`（本仓库 main 已支持，
旧镜像需先更新；未更新的旧后端会被脚本自动识别并跳过这两个字段，其余字段照常同步）。
