# 油猴脚本

本目录用于存放备件管理系统配套的 Tampermonkey / Violentmonkey 用户脚本。

> 目录调整说明：本目录原为 `example/script/`，已随仓库结构整理迁移到 `docs/references/scripts/`。
> 两个脚本的 `@updateURL` / `@downloadURL` 已同步指向新地址并递增 `@version`；已安装旧地址的
> 脚本不会自动更新，需要在脚本管理器中按本目录的新地址更新一次（或重新新建脚本粘贴内容）。

## 华友印尼数据平台同步

脚本文件：`huayou-new-sync.user.js`

功能：

- 自动登录华友印尼数据平台，按「申购单号」整单查询“物料申购跟踪”，同一申购单号只发起一次
  平台查询，并在后端 `/purchase-record-sync/order-targets` 的目标基础上整单批量回写
  （`/purchase-record-sync/orders/{申购单号}/apply`），避免按追溯号逐条查询产生大量平台请求。
- 平台相邻两次报表查询至少间隔 10 秒（限频）；登录不计入。
- 每个申购单最近一次成功同步的时间写入浏览器 IndexedDB（华友印尼数据平台站点域），
  3 天内不再重复请求同一申购单，避免频繁重复查询；演练模式不写记录。
- 采购人、采购合同号、船名、状态只补空值、只进不退（已申购 → 已采购 → 部分入库 → 已入库），
  与旧脚本语义一致；某申购单号下多个追溯号一次查询、一次回写。
- 合同签订日期取自平台报表「物料申购跟踪」的 **合同签订时间** 列（据真实 HAR 的 `page/data`
  确认：该列为表头第 32 列，紧跟「采购合同号」之后），同样只补空值、不覆盖人工填写；该字段在
  本系统是**物资级**字段，按追溯号逐行回写。多个批次时取最新有效日期；平台若返回无法识别的
  日期文本则跳过该字段（宁可不填，也不写错日期）。
- 兼容与提示：报表没有该列时脚本会在日志中提示一次并只同步其余字段；后端尚未更新（不认识该
  同步字段）时自动降级为旧字段列表继续同步，不会整批中断。
- 首次请求对物料系统接口与本系统接口做严格结构校验；报表结构或接口契约与脚本不符时立即
  终止并给出日志，避免对一批申购单空跑、误写。
- 支持单次同步、自动模式、单次申购单数和演练模式。
- 同步目标项目在悬浮窗「连接与同步设置」的“项目”下拉框中选择，默认使用系统的默认项目（已保存项目
  被停用时会自动回退到默认项目并记住）；后端自多项目版本起要求业务接口携带 `X-Project-Id` 请求头
  （`GET /api/v1/projects` 除外），项目未选择或已失效时脚本只提示一次「项目未选择或已失效……」并
  中止本次同步。
- 悬浮窗内容输入即自动保存到油猴本地存储；密码与接口令牌以明文显示（`type=text`），
  请仅在个人电脑上使用。

安装与使用：

1. 在 Tampermonkey 或 Violentmonkey 中新建脚本，粘贴 `huayou-new-sync.user.js` 的完整内容并保存。
2. 打开华友印尼数据平台站点 `http://43.154.152.157:8080/`（悬浮窗在该网站右下角出现）。
3. 在悬浮窗中填写物资平台账号、密码、本系统接口令牌（管理端 API Token）。内容输入后会自动
   保存，也可点“保存设置”确认。物资平台账号默认是 `huaxing_jianxiu`。保存令牌后“项目”下拉框会
   列出已启用的项目（默认选中系统默认项目），同步只写入所选项目的数据。
4. 关闭“演练模式”后正式写入（默认已关闭演练模式）。

凭据保存在用户脚本管理器的私有存储中，不写入仓库源码或网页 `localStorage`。查询时脚本会在
后台短暂打开参数化报表页，得到结果后自动关闭。脚本 3.x 依赖后端“按申购单号整单目标/回写”
接口（见 `server/app/api/v1/purchase_record_sync.py`）；合同签订日期需要后端满足
`purchase-record-sync` 字段白名单包含 `contract_sign_date`（本仓库 main 已支持，旧镜像需先更新）。

## 华友何佳状态同步

脚本文件：`huayou-hejia-sync.user.js`

功能：

- 在备件管理系统右下角显示可拖动、可最小化的悬浮窗。
- 通过申购记录同步接口（`/purchase-record-sync/*`）查询“存在待补齐字段且追溯号不为空”的申购记录。
- 自动登录华友何佳系统，调用“查询报表 → 物资状态查询”的数据接口。
- 按追溯号读取业务员、当前状态、合同号、船号、集港日期、集港港口和发船日期，并参数化更新本系统。
- 支持单次同步、自动模式、批次数量、执行间隔和演练模式。
- 同步目标项目在悬浮窗「连接与同步设置」的“项目”下拉框中选择，默认使用系统的默认项目（已保存项目
  被停用时会自动回退到默认项目并记住）；后端自多项目版本起要求 `/purchase-record-sync/*` 接口携带
  `X-Project-Id` 请求头（`GET /api/v1/projects` 除外），项目未选择或已失效时脚本只提示一次并中止
  本次同步。

### 安装

1. 浏览器安装 Tampermonkey 或 Violentmonkey。
2. 新建脚本，将 `huayou-hejia-sync.user.js` 的内容完整粘贴并保存。
3. 打开 `https://materials-manager.qcloud.19890605.xyz`。
4. 在悬浮窗中填写何佳密码、本系统接口令牌（管理端 API Token），然后保存设置。保存后“项目”下拉框
   会列出已启用的项目（默认选中系统默认项目），同步只写入所选项目的数据。
5. 建议先开启“演练模式”执行一次，检查日志后再关闭演练模式进行正式同步。

何佳账号默认填入 `hync`，密码不会写入仓库文件，而是保存在油猴扩展的脚本私有存储中。

### 同步规则

- 待处理范围：`purchase_request_line.salesperson` 为空，且 `trace_no` 不为空。
- 何佳追溯码字段：`var_trackno`。
- 何佳当前状态字段：`flag_prog`。
- 何佳业务员字段：`var_reqclerk`。
- 合同号、船号、集港日期、集港港口和发船日期优先按何佳内部字段名识别，也会按中文列标题兼容识别。
- 同一追溯号返回多个批次时，不同状态、业务员、合同号、船号和港口会去重后使用 `/` 合并；日期取最新的有效日期。
- 同步只补齐本系统中的空字段，不覆盖人工已填写的合同和发运信息。
- 何佳未返回部分字段时仍可更新其他已获取字段；仍有空字段的追溯号会在后续任务中再次查询。
- 自动模式默认关闭，防止安装后立即写入生产数据。

### 安全说明

- 账号密码保存在用户脚本管理器中，不写入网页 `localStorage`，也不写入仓库源码。
- 数据库写入使用命名参数，不把状态、业务员或追溯号直接拼接进 SQL。
- 更新语句只处理执行时仍缺失业务员的记录，避免覆盖人工补录结果。
- 建议第一次使用时开启演练模式，确认查询结果后再正式写入。
