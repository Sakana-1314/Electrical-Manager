# 油猴脚本

本目录用于存放备件管理系统配套的 Tampermonkey / Violentmonkey 用户脚本。

> 目录调整说明：本目录原为 `example/script/`，已随仓库结构整理迁移到 `docs/references/scripts/`。
> 两个脚本的 `@updateURL` / `@downloadURL` 已同步指向新地址并递增 `@version`；已安装旧地址的
> 脚本不会自动更新，需要在脚本管理器中按本目录的新地址更新一次（或重新新建脚本粘贴内容）。

## 两个脚本的分工（华友单号阈值）

华友的两套系统（新版「印尼数据平台」与旧版「何佳 / 华越物资供应追踪系统」）数据不重叠，
本目录的两个脚本按**申购单号**分工，互不重复、也互不遗漏：

| 脚本 | 负责的申购单号 | 查询的系统 |
| --- | --- | --- |
| `huayou-new-sync.user.js` | **>= 阈值**（默认 `P05SG0300`，`min_purchase_order_no`） | 华友印尼数据平台 |
| `huayou-hejia-sync.user.js` | **< 阈值**（默认 `P05SG0300`，`max_purchase_order_no`） | 华友何佳（旧系统） |

阈值（默认 `P05SG0300`）在两个脚本的悬浮窗里都能改：新版脚本是「申购单号起始」，旧版脚本是
「申购单号上限（不含）」。两侧都改了之后仍互补，不会出现同一单被两个脚本同时写入。

后端 `GET /api/v1/purchase-record-sync/targets` 与 `.../order-targets` 支持
`min_purchase_order_no`（含端点）与 `max_purchase_order_no`（**不含**端点）两个查询参数，
即按半开区间 `[min, max)` 过滤；旧镜像缺少 `max_purchase_order_no` 时，旧版脚本会在客户端
再过滤一次，只是会多拉几单、不会写错数据。

## 华友印尼数据平台同步

脚本文件：`huayou-new-sync.user.js`

功能：

- 自动登录华友印尼数据平台，按「申购单号」整单查询“物料申购跟踪”，同一申购单号只发起一次
  平台查询，并在后端 `/purchase-record-sync/order-targets` 的目标基础上整单批量回写
  （`/purchase-record-sync/orders/{申购单号}/apply`），避免按追溯号逐条查询产生大量平台请求。
- 只处理申购单号 `>= min_purchase_order_no`（默认 `P05SG0300`）的申购单；更早的申购单由
  旧系统脚本 `huayou-hejia-sync.user.js` 负责（见上一节的分工表）。
- 平台相邻两次报表查询至少间隔 10 秒（限频）；登录不计入。
- 每个申购单最近一次成功同步的时间写入浏览器 IndexedDB（华友印尼数据平台站点域），
  3 天内不再重复请求同一申购单，避免频繁重复查询；演练模式不写记录。
- 采购人、采购合同号、船名、状态只补空值、只进不退（已申购 → 已采购 → 部分入库 → 已入库），
  与旧脚本语义一致；某申购单号下多个追溯号一次查询、一次回写。
- 合同签订日期取自平台报表「物料申购跟踪」的 **合同签订时间** 列（据真实 HAR 的 `page/data`
  确认：该列为表头第 32 列，紧跟「采购合同号」之后），同样只补空值、不覆盖人工填写；该字段在
  本系统是**物资级**字段，按追溯号逐行回写。多个批次时取最新有效日期；平台若返回无法识别的
  日期文本则跳过该字段（宁可不填，也不写错日期）。
- 兼容与提示：报表没有该列时脚本会在日志中提示一次并只同步其余字段；后端尚未更新（不认识该
  同步字段）时自动降级为旧字段列表继续同步，不会整批中断。
- 首次请求对物料系统接口与本系统接口做严格结构校验；报表结构或接口契约与脚本不符时立即
  终止并给出日志，避免对一批申购单空跑、误写。
- 支持单次同步、自动模式（仅北京时间 02:00–06:00 执行）、单次申购单数和演练模式。
- 同步目标项目在悬浮窗「连接与同步设置」的“项目”下拉框中选择，默认使用系统的默认项目（已保存项目
  被停用时会自动回退到默认项目并记住）；后端自多项目版本起要求业务接口携带 `X-Project-Id` 请求头
  （`GET /api/v1/projects` 除外），项目未选择或已失效时脚本只提示一次「项目未选择或已失效……」并
  中止本次同步。
- 悬浮窗内容输入即自动保存到油猴本地存储；密码与接口令牌以明文显示（`type=text`），
  请仅在个人电脑上使用。

安装与使用：

1. 在 Tampermonkey 或 Violentmonkey 中新建脚本，粘贴 `huayou-new-sync.user.js` 的完整内容并保存。
2. 打开华友印尼数据平台站点 `http://43.154.152.157:8080/`（悬浮窗在该网站右下角出现）。
3. 在悬浮窗中填写物资平台账号、密码、本系统接口令牌（管理端 API Token）。内容输入后会自动
   保存，也可点“保存设置”确认。物资平台账号默认是 `huaxing_jianxiu`。保存令牌后“项目”下拉框会
   列出已启用的项目（默认选中系统默认项目），同步只写入所选项目的数据。
4. 关闭“演练模式”后正式写入（默认已关闭演练模式）。

凭据保存在用户脚本管理器的私有存储中，不写入仓库源码或网页 `localStorage`。查询时脚本会在
后台短暂打开参数化报表页，得到结果后自动关闭。脚本 3.x 依赖后端“按申购单号整单目标/回写”
接口（见 `server/app/api/v1/purchase_record_sync.py`）；合同签订日期需要后端满足
`purchase-record-sync` 字段白名单包含 `contract_sign_date`（本仓库 main 已支持，旧镜像需先更新）。

## 华友何佳状态同步（旧系统）

脚本文件：`huayou-hejia-sync.user.js`

功能：

- 在备件管理系统右下角显示可拖动、可最小化的悬浮窗（与新版脚本同一套交互：输入即保存、
  演练模式、日志面板）。
- 只处理申购单号 `< 阈值`（默认 `P05SG0300`）的旧系统数据：通过后端整单目标接口
  `/purchase-record-sync/order-targets?max_purchase_order_no=...` 取目标，阈值以上的申购单直接
  跳过并推进游标（留给新版脚本）。
- 按「申购单号」整单查询华友何佳“物资状态查询”：一个申购单只查询一次
  （条件 `v_rpt_progre.var_reqno like '%<申购单号>%'`，`pageSize=800`，超过一页自动按页拉全），
  再按追溯码分组，最后整单一次批量回写 `/purchase-record-sync/orders/{申购单号}/apply`。
- 回写字段：业务员（`var_reqclerk`）、当前状态（`flag_prog`）、合同号（`var_conno`）、
  船号（`var_shipno`）、集港日期（`date_rcv`）、集港港口（`name_post`）、发船日期（`date_ship`）
  与物资级合同签订日期（`date_sign`）。字段优先按何佳内部字段名识别，改过名时按中文表头兜底。
- 只补空值、不覆盖人工填写；状态只进不退（后端白名单只认已申购 / 已采购 / 部分入库 / 已入库，
  何佳的“合同待签”“生产中”等过程状态不会被写入）。
- 同一追溯号返回多个批次时，业务员、状态、合同号、船号、港口去重后用 `/` 合并（上限 128 字符）；
  日期取最新有效值；何佳把「无日期」写成 `1900-01-01` 之类的占位值一律忽略（宁可不填也不写错）。
- 每个申购单最近一次成功同步的时间写入浏览器 IndexedDB（备件管理系统站点域），3 天内不再重复
  查询何佳；演练模式不写记录，也不会占用冷却期。
- 首次请求对何佳报表配置、查询结果与本地接口做结构校验；报表结构或接口契约与脚本不符时
  立即终止并给出日志，避免对一批申购单空跑、误写。
- 何佳查询复用浏览器现有何佳会话；返回“登录超时或请求未认证”（403）或跳到登录页（302）时，
  用悬浮窗里的何佳账号密码自动补登一次并重试。何佳挂在 Cloudflare 后面偶发 5xx / 524（源站超时），
  这类瞬时错误会自动重试（最多 3 次），不会一次抖动就整批失败。
- 支持单次同步、自动模式（仅北京时间 02:00–06:00 执行）、单次申购单数和演练模式。
- 同步目标项目在悬浮窗「连接与同步设置」的“项目”下拉框中选择，默认使用系统的默认项目（已保存项目
  被停用时会自动回退到默认项目并记住）；后端自多项目版本起要求 `/purchase-record-sync/*` 接口携带
  `X-Project-Id` 请求头（`GET /api/v1/projects` 除外），项目未选择或已失效时脚本只提示一次并中止
  本次同步。

### 安装

1. 浏览器安装 Tampermonkey 或 Violentmonkey。
2. 新建脚本，将 `huayou-hejia-sync.user.js` 的内容完整粘贴并保存。
3. 打开 `https://materials-manager.qcloud.19890605.xyz`。
4. 在悬浮窗中填写何佳密码、本系统接口令牌（管理端 API Token），然后保存设置。保存后“项目”下拉框
   会列出已启用的项目（默认选中系统默认项目），同步只写入所选项目的数据。
5. 确认「申购单号上限（不含）」是约定阈值（默认 `P05SG0300`）。
6. 建议先开启“演练模式”执行一次，检查日志后再关闭演练模式进行正式同步。

何佳账号默认填入 `hync`（组织固定为「华越物资供应追踪系统」），密码不会写入仓库文件，
而是保存在油猴扩展的脚本私有存储中。

### 依赖的后端接口

脚本 2.x 依赖后端支持按申购单号上限过滤（本仓库 main 已支持，旧镜像需先更新）：

- `GET /api/v1/purchase-record-sync/order-targets`：`max_purchase_order_no` 只返回单号
  **严格小于**该值的整单目标；后端未升级时该参数被忽略，脚本会在客户端再过滤一次。
- `POST /api/v1/purchase-record-sync/orders/{申购单号}/apply`：整单批量回写（沿用旧版）。
- 合同签订日期需要 `purchase-record-sync` 字段白名单包含 `contract_sign_date`
  （本仓库 main 已支持）；后端不认识该字段时脚本自动降级为不含该字段的旧字段列表继续同步。

### 同步规则

- 待处理范围：`purchase_request_line.salesperson` 为空，且 `trace_no` 不为空。
- 何佳追溯码字段：`var_trackno`；何佳申购单号字段：`var_reqno`。
- 何佳当前状态字段：`flag_prog`；何佳业务员字段：`var_reqclerk`。
- 合同号、船号、集港日期、集港港口、发船日期与合同签订日期优先按何佳内部字段名识别，
  也会按中文列标题兼容识别。
- 同步只补齐本系统中的空字段，不覆盖人工已填写的合同和发运信息。
- 何佳未返回部分字段时仍可更新其他已获取字段；仍有空字段的追溯号会在后续任务中再次查询。
- 自动模式默认关闭，防止安装后立即写入生产数据。

### 安全说明

- 账号密码保存在用户脚本管理器中，不写入网页 `localStorage`，也不写入仓库源码。
- 数据库写入使用命名参数，不把状态、业务员或追溯号直接拼接进 SQL；查询条件里的申购单号会做
  单引号转义。
- 更新语句只处理执行时仍缺失业务员的记录，避免覆盖人工补录结果。
- 建议第一次使用时开启演练模式，确认查询结果后再正式写入。
